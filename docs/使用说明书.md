# website-teardown 使用说明书（中文）

> 输入几个公开网址，得到一张竞品对比表：平台、配色、字体、价格带、装了什么 App。
> 全程零依赖，只要有 Python。**这是分析工具，不是复制工具。**

---

## 1. 它能给你什么（先看结果）

跑完你会得到这么一张表：

| Site | Platform | Colors | Fonts | Price band | Apps |
| --- | --- | --- | --- | --- | --- |
| https://kettl.co | Shopify | #dd6444 #467c99 #38637a | otto | $26–$150 | Klaviyo, Recharge |
| https://www.allbirds.com | Shopify | #e0dacf #03143b #9c0f0f | geograph, akkurat mono | $5–$105 | Yotpo, Swiper, GA |
| https://www.onyxcoffeelab.com | Shopify | #007aff #b00923 #d28467 | montserrat, bajern | $40–$40 | Klaviyo, Recharge, Gorgias |

配合下面这段解读，就是一份可以直接交给客户的竞品调研：

> 6 个样本全部使用 Shopify，平台已无差异化。
> 字体全部为品牌定制字体，无人使用免费模板字体。
> 配色以暖棕、陶土、红为主流，冷色调属于刻意差异化。
> Klaviyo 出现率 6/6，是这一品类的邮件营销标配。

## 2. 准备工作：只要 Python

不需要 `pip install` 任何东西，代码只用 Python 标准库。

**检查版本：**

```powershell
python --version
```

看到 `Python 3.8.x` 或更高就行。

**如果提示「python 不是内部或外部命令」：**

- 试 `py -3 --version`
- 或从 [python.org](https://www.python.org/downloads/) 装一个，安装时勾选 **Add Python to PATH**

## 3. 第一次跑起来

在仓库根目录（`website-teardown` 这一层）执行：

```powershell
python skills\website-teardown\scripts\analyze.py kettl.co
```

就这一条。**网址可以只写域名**，程序会自动补 `https://`。

正常输出：

```
[1/1] https://kettl.co
| Site | Platform | Colors | Fonts | Price band | Apps |
| --- | --- | --- | --- | --- | --- |
| https://kettl.co | Shopify | #467c99 #38637a #90b0c2 | otto | $26–$150 | Klaviyo, Recharge |
```

> ⚠️ Windows 上那行 `[1/1] ...` 可能显示成红色，**这不是报错**。PowerShell 会把程序的进度输出（stderr）标红。
> 嫌碍眼就在命令末尾加 ` 2>$null`。

## 4. 五种日常用法

### 用法一：对比 3 个竞品（最常用）

```powershell
python skills\website-teardown\scripts\analyze.py kettl.co allbirds.com fellowproducts.com
```

词之间用空格隔开，不限制数量上限（受 `--max-pages` 限制，默认 20）。

### 用法二：生成报告文件，发给客户或贴进 PPT

```powershell
python skills\website-teardown\scripts\analyze.py kettl.co allbirds.com --md 竞品对比.md
```

生成的 `竞品对比.md` 自带说明脚注和分析时间戳，可以直接用。

### 用法三：存原始数据，方便以后比对有没有改版

```powershell
python skills\website-teardown\scripts\analyze.py kettl.co --json 2026-10-kettl.json
```

一个月后再跑一次，两份 JSON 一比就知道对方换了什么字体、加了什么 App。

### 用法四：一次跑十个站（或用文件喂列表）

少量站点直接写在命令后面：

```powershell
python skills\website-teardown\scripts\analyze.py 站点1 站点2 ... 站点10 --delay 3 --timeout 20
```

站点多了就写成文件（一行一个，`#` 开头是注释），这样能复用、能版本管理：

```powershell
python skills\website-teardown\scripts\analyze.py --input urls.txt --delay 3
```

`urls.txt` 长这样：

```
# 咖啡类
kettl.co
allbirds.com
# 家居类
fellowproducts.com
```

- `--delay 3`：每个站之间等 3 秒（默认 2 秒 + 随机 0–1 秒），**别调太小**
- `--timeout 20`：慢站多给点时间，默认 15 秒
- 文件存成 UTF-8 带不带 BOM 都行，程序会自动处理

### 用法五：当作 AI 助手的技能用

把整个 `skills\website-teardown` 文件夹复制到你的 skills 目录（以 Claude Code 为例）：

```powershell
Copy-Item -Recurse skills\website-teardown "$env:USERPROFILE\.claude\skills\"
```

之后不用记命令了，直接说「**帮我分析这几个站的竞品情况：kettl.co、allbirds.com**」，
助手会自己调用，并按 `SKILL.md` 的要求先给你结论、再给表。

## 5. 参数速查

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `--input 文件名` | 不读取 | 从文件读网址列表，一行一个，`#` 是注释 |
| `--md 文件名` | 不生成 | 输出 Markdown 报告 |
| `--json 文件名` | 不生成 | 输出原始结构化数据 |
| `--max-pages N` | `20` | 单次最多分析几个站（安全上限） |
| `--delay 秒` | `2.0` | 请求间隔基数，实际会再加 0–1 秒随机 |
| `--timeout 秒` | `15` | 单个请求超时 |
| `--user-agent 字符串` | `website-teardown/0.1 (+仓库地址)` | 表明自己是谁，**不建议改** |
| `--ignore-robots` | 关闭 | 忽略 robots.txt。**只对你自己的站用** |

查看完整帮助：

```powershell
python skills\website-teardown\scripts\analyze.py --help
```

## 6. 输出怎么读

| 列 | 含义 | 什么算「有用的信号」 |
| --- | --- | --- |
| **Platform** | 识别出的建站平台 | 全部相同 → 平台不是差异化点；只有一家不同 → 值得看看那家为什么选别的 |
| **Colors** | 页面里出现频率最高的非中性色 | 3 家同色系、1 家不同 → 那家在做差异化 |
| **Fonts** | `font-family` 里排名靠前的字体 | 全是自定义名（如 `gtzirkon-book`）→ 品牌做了定制字体；出现 `arial`/`roboto` → 大概率用模板 |
| **Price band** | 页面可见金额的最低–最高 | 看价格带分布：集中 / 分散 / 有没有 9.99 这种尾数定价 |
| **Apps** | 识别出的第三方服务 | 出现率最高的那几个，就是这个品类的技术标配 |

**判断小技巧**：先横向看「哪些列全部一样」，那些就是行业标配、不用再纠结；再看「哪一行跟别人不一样」，那才是这家店的策略。

## 7. 出错了怎么办

| 你看到的 | 真实含义 | 该怎么做 |
| --- | --- | --- |
| `FAIL: skipped: robots.txt disallows` | 对方网站禁止自动访问 | **换一个站，不要绕过**。这是设计如此 |
| `FAIL: HTTP 403` / `HTTP 429` | 被反爬拦截 / 请求太频繁 | 停下来。不要换 UA 重试，那是越线行为 |
| `SSL: CERTIFICATE_VERIFY_FAILED` | 证书校验失败，常见于公司代理或网络中间人 | 换网络试试；或暂时跳过这个站 |
| `timeout` | 站点慢，或被你的网络挡了 | 加 `--timeout 30` 重试一次；还不行就是连不上 |
| 终端里中文/破折号显示成乱码 | Windows 控制台编码是 GBK | 用 `--md` 输出到文件，文件是 UTF-8 正常的 |
| `[1/1] ...` 显示成红色 | PowerShell 把 stderr 标红，不是错误 | 忽略，或加 `2>$null` |
| `python 不是内部或外部命令` | Python 没装或没进 PATH | 见第 2 节 |

## 8. 常见疑问

**Q：价格为什么不准？**
价格是从页面可见文本里按货币符号抓的，会混进运费、起送价、赠品价。
比如 `fellow` 跑出 `$1–$399.95`，那个 `$1` 是噪音。**价格列只看区间大致位置，别当精确数据。**

**Q：字体显示 `inherit` 或空？**
说明这个站的字体是通过 JS 动态注入的，静态 HTML 里没有。这是抓取方式的天花板，不是 bug。

**Q：能分析需要登录的页面吗？**
**不能，也不应该。** 绕过登录等于绕过访问控制，可能违法。工具遇到此类站会直接失败。

**Q：能抓到对方的销量、转化率吗？**
不能。公开页面没有这些数据，任何声称能抓的工具都是在猜。

**Q：会被对方发现吗？**
会。工具用的是真实 User-Agent，对方日志里能看到 `website-teardown/0.1`。这是故意的，**诚实比隐藏安全**。

**Q：能一次跑 500 个站吗？**
技术上能，但别这么干。默认 20 个上限是刻意设的——小批量分析是研究，大批量抓取是另一回事。

## 9. 合规红线（三句话）

1. **只抓公开页面**，不碰登录、付费墙、验证码。
2. **默认遵守 robots.txt**，被拒就换站，不绕过。
3. **只提元数据，不复制内容**——不下载图片、不保存文案、不分发截图。

你用这个工具做的事，责任在你。
